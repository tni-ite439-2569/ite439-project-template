## วิธี build APK

```bash
flutter clean
flutter pub get
flutter build apk --release
```

ไฟล์ที่ได้อยู่ที่ `build/app/outputs/flutter-apk/app-release.apk` ห้าม commit ไฟล์ APK ลง repo ให้แนบในช่องส่งงาน Final ใน Teams
